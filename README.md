# VANGUARD ATELIER // Haute Menswear

A modern, high-fashion multi-page luxury menswear atelier website featuring an Alabaster & Cashmere Stone light aesthetic, cinematic scroll-scrubbed zoom animations, custom AI editorial imagery, and bespoke interactive craftsmanship tools.

![Vanguard Atelier](public/images/hero-menswear.jpg)

## ✨ Features

- **Cinematic Full-Bleed Hero**: Interactive 5-look silhouette switcher (`01`–`05`) with smooth GSAP cross-fades, scroll-scrubbed optical zoom, and preloaded high-fashion editorial photography.
- **Multi-Page Architecture**:
  - `index.html` — Editorial home runway, manifesto, brand pillars, video monograph, infinite marquee ticker.
  - `collection.html` — Complete 8-piece bespoke catalog with category filtering, price sorting, interactive 3D card tilt, and optical loupe zoom modal.
  - `lookbook.html` — High-fashion runway monograph looks with styling breakdown.
  - `craftsmanship.html` — Interactive garment anatomy blueprint with clickable hotspot pins and 3.0x live loupe magnifier.
  - `contact.html` — Private fitting reservation dossier form and flagship atelier salon contacts (Milan, London, Paris, Tokyo).
- **Minimalist Luxury Navbar**: Translucent Italian marble white (`#faf8f5`/95) with backdrop blur, razor-thin borders, and active link indicators.
- **Ambient Atelier Soundscape**: Interactive sound toggle with ambient sound synthesis.
- **Interactive Shopping Bag**: Drawer cart with quantity controls, subtotal computation, and slide-out animation.
- **Zero FOUC Architecture**: Render-blocking stylesheets and inline CSS guards ensuring 0ms flash of unstyled content on refresh.

## 🛠️ Tech Stack

- **Vite 6** — Lightning-fast development & production bundling
- **Tailwind CSS 3** — Utility-first styling with custom typography and color tokens
- **GSAP 3 & ScrollTrigger** — Fluid animation choreography and scroll scrub
- **Lenis** — Ultra-smooth inertia scrolling
- **Lucide Icons** — Clean iconography

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/maheshkumarsaini8769-del/vanguard-menswear.git

# Navigate to project directory
cd vanguard-menswear

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
